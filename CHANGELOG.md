# Changelog

## 1.0.1 — 2026-11-03

- Add Ctrl+wheel terminal font zoom and Ctrl+Shift+C/V clipboard shortcuts.
- Support file transfers between saved SSH sessions with independent endpoint selectors.
- Connect SFTP without opening a terminal; retry authentication with a new password.
- Open file transfer without an existing connection and use the selected session.
- Add native file/folder upload pickers and download destination selection.
- Show source and destination hosts in transfer tasks and theme endpoint selectors.

## 1.0.0 — 2026-11-02

- Add global SSH profiles, custom terminals and switchable/duplicable instances.
- Save successful password credentials using VS Code SecretStorage.
- Add dual-pane SFTP browsing, drag-and-drop and task results.
- Add resizable layouts and VS Code theme/font integration.
- Add configurable English/Simplified Chinese UI and translated manifest labels.
- Prepare documentation, Apache-2.0 licensing, CI and package validation.

First release. See README for supported features and current limitations.
